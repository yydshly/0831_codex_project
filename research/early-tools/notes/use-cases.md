# 使用场景

## 1. 早期采用者发现新产品

### 目标

在产品进入大众市场之前发现有意思的工具，获得早期用户名、折扣、候补资格或与创始人直接交流的机会。

### 工作流

1. 选择 Waitlist、Alpha、Beta 或 Early 阶段。
2. 按 AI、Productivity、Developer Tools 等主题和 Web、macOS、API 等平台缩小范围。
3. 查看详情页的创始人、开放方式、Deal、Lifeline 和相似产品。
4. 访问官网、加入 Waitlist，或订阅 Newsletter 等待阶段变化。

### 适用边界

平台适合寻找线索，不负责保证产品稳定、数据安全或长期运营。

## 2. 独立开发者冷启动发布

### 目标

用较低成本获得第一批高意向访问者，并建立可被搜索引擎长期发现的产品页面。

### 工作流

1. 使用 Magic Link 登录并提交产品。
2. 提供清晰的定位、阶段、平台、创始人资料和可验证官网。
3. 选择免费策展或付费快速 Listing。
4. 设计可衡量的 Deal，例如折扣、额度、预留用户名或候补优先级。
5. 通过页面访问、外链点击和注册来源判断是否匹配目标受众。

### 适用边界

early.tools 只能贡献一个分发渠道。它不能代替用户访谈、内容营销、社群运营、销售或产品留存。

## 3. 创业验证与分发规划

### 目标

从想法阶段逐步完成问题、方案、商业和规模验证，并建立外部发布清单。

### 工作流

1. 在 Validation Experiments 中按 Desirability、Viability、Feasibility 和 Responsibility 选择实验。
2. 根据速度、可靠性和成本确定执行顺序。
3. 在 Startup Resources 中按 Idea、Concept、MVP、Business、Scale 查找工具与参考资料。
4. 在 Directories 中按价格和难度建立提交队列。
5. 记录已提交、已通过和待跟进的渠道。

### 适用边界

实验库提供方法，不会自动得到高质量样本、执行实验或证明产品市场匹配。

## 4. 产品经理与创新团队技术侦察

### 目标

持续观察新工具、新交互和新商业模式，形成竞品清单与趋势假设。

### 工作流

1. 按主题建立定期扫描范围。
2. 比较同类产品的定位、平台、阶段和开放方式。
3. 通过 Lifeline 观察从 Waitlist 到 Public 的变化。
4. 订阅 Newsletter 或 RSS，减少手动重复搜索。
5. 对重要候选产品进入官网进行进一步验证。

### 适用边界

目录没有完整市场份额、客户案例和企业安全信息，不能直接支持采购结论。

## 5. 投资人与分析师线索发现

### 目标

发现尚未广泛传播的团队、产品方向与重复出现的赛道。

### 工作流

1. 从 Early Backlog 和 Founder Directory 建立候选池。
2. 观察同一创始人的产品与发布历史。
3. 使用平台阶段、互动和 Lifeline 作为初筛信号。
4. 到公司官网、公司注册信息、融资数据库和创始人渠道交叉验证。

### 适用边界

浏览量、外链点击和编辑标签不是收入、留存、融资或团队能力的替代指标。

## 6. 创业服务商、招聘方和合作伙伴获客

### 目标

寻找正在发布、融资、招聘或需要设计、开发、营销服务的创始人。

### 工作流

1. 在 Founder Directory 中按产品阶段和可联系渠道筛选。
2. 研究对方产品和近期发布历史。
3. 基于真实需求进行小规模、个性化联系。
4. 记录回复与转化，避免重复和无关触达。

### 适用边界

Founder 数据不应被用于无差别批量邮件。扩展任何自动外联能力都需要同意、退订、频率限制和数据删除机制。

## 7. 面向创始人的品牌投放

### 目标

把招聘、云服务、设计、支付、开发者工具等产品展示给早期创业者。

### 工作流

1. 判断受众主题与 Sponsor 流量是否匹配。
2. 使用带 UTM 的落地页和专属优惠。
3. 同时观察平台自报点击、站内转化和最终付费。
4. 用实际 CAC 与客户质量决定是否续费。

### 适用边界

Sponsor 页数字是平台自报且含“平均到最佳”区间，不能直接视作投放保证。

## 场景优先级判断

| 场景 | 匹配度 | 原因 |
| --- | --- | --- |
| AI/Web 早期产品发现 | 高 | 当前目录主题与平台分布高度匹配 |
| 独立开发者发布 | 高 | 受众集中、入口清晰、成本相对可控 |
| 创业验证与目录分发 | 高 | 会员工具直接覆盖该工作流 |
| 创新团队趋势扫描 | 中高 | 有阶段和主题结构，但缺少深度企业数据 |
| 投资线索发现 | 中 | 适合 sourcing，不适合 diligence |
| 企业采购 | 低 | 缺少安全、合规、SLA 与客户证据 |
| 通用消费者应用商店 | 低 | 当前覆盖偏英文、AI、Web 和 Founder 生态 |
