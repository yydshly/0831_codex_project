# XPADE Face Liquify Capability Lab：交付契约

## 设计契约

| 字段 | 决策 |
| --- | --- |
| Entry mode | Revision-led functional extension |
| Request revision | 3 |
| Target user and context | 需要用接近真实业务图片判断人像产品效果、场景覆盖和当前几何能力边界的产品负责人、开发者、设计者与 AI 人像创作者 |
| Desired first impression | 先看到写实人像的可拖动前后对比与多场景选择，再追溯 SVG 几何实验和能力归属 |
| Visual ambition | Editorial |
| Experience architecture | Hybrid Workspace |
| Visual constraints | 延续深色、琥珀色与工作台感；主业务演示使用本地写实合成人像，保留 SVG 作为技术解释层；信息层级高于装饰 |
| Information constraints | 明确区分“AI 生成的虚拟人物写实样片”“预生成目标效果”“浏览器实时控制”“原网页已验证能力”和“产品建议” |
| Operation constraints | 纯静态前端；无后端、登录、真实人脸上传或第三方推理服务；核心演示无需网络 |
| State constraints | 保留几何实验台与职业头像状态；新增六类业务场景、写实前后对比拖杆、场景选择、原图/结果快速切换；选中场景与比较位置可本地恢复 |
| Environment constraints | 独立 Vite 应用；支持 GitHub Pages 子路径；固定深色主题；桌面、平板与 390px 手机可用 |
| Primary journey | 选择真实业务场景 → 拖动写实样片的前后对比 → 阅读该场景的能力组合与产品价值 → 进入职业头像流程或 SVG 几何实验 → 追溯技术原理与边界 |
| User-defined phases | 写实图片演示；多业务场景；职业头像业务流程；几何能力演示；技术原理；使用场景；可扩展方向 |
| Required artifacts | 本地写实合成样片、可运行 Demo、Demo README、研究 README、技术原理笔记、根索引、浏览器验证记录 |
| Autonomy authorization | 用户明确要求“新建子项目”；允许在现有研究仓库约定内创建并验证独立子项目 |
| User-decision boundary | 若需要用户/员工真人照片、照片上传、摄像头、运行时真实 AI 推理、企业登录、后端审批或外部部署，必须另行授权 |
| Observable completion criteria | 至少六类业务场景使用本地写实虚拟人物样片；每个场景有身份一致的前后目标效果与能力归属；拖杆、键盘和快速切换可比较；图片加载失败有回退；原职业头像与 SVG 实验保持可用；1440px、768px、390px 无横向溢出；首屏场景图片加载可接受；`npm run build` 通过；文档可复现 |

## 设计方向

| 决策 | 方向 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 信息层级 | 写实场景对照为首要内容，业务流程、几何实验、证据与结论随后展开 | 首屏只保留定位、写实案例入口和必要说明 | 第一次扫描能识别“这是什么、可看哪些真实业务效果、哪些能力属于当前库” |
| 字体角色 | 展示标题、正文、数值标签三级 | 中文正文保持舒适行长；数值使用等宽数字 | 390px 下无孤立竖排或标签截断 |
| 色彩与材质 | 固定深色中性色＋琥珀强调＋青绿色数据反馈 | 强调色只表示交互和数据状态 | 内容不依赖颜色单独表达 |
| 动效 | 只用于解释参数变化和步骤切换 | 尊重 `prefers-reduced-motion` | reduced-motion 下信息和操作不丢失 |
| 响应式 | 桌面双栏实验台，窄屏堆叠 | 控件不脱离文档流，不使用固定侧栏 | 390px 仍可完成完整主流程 |
| 演示真实性 | 业务案例使用 AI 生成的虚拟人物写实样片，技术层保留原创 SVG | 显著标注“虚拟人物、预生成目标效果、非运行时 AI”；不使用可识别真人或声称生产精度 | 用户能判断接近照片的目标效果，同时不会误认已运行真实模型 |
| 产品层归属 | 将质量检查、背景、光线、皮肤、着装与审批标为产品层模拟；将几何微调标为当前库能力的合成驱动 | 能力归属在工作区内始终可见，不能仅靠颜色表达 | 关闭 XPADE 层只恢复面部几何，其他职业化效果保持不变 |
| 业务闭环 | 员工确认与 HR 审核只改变本地页面状态 | 明示“不发送到 HR 或服务器” | 用户可以完整体验流程，同时不会误认已接入企业系统 |
