# Write Then Publish 独立研究档案

这是一个独立、静态的 Vite + Vanilla JavaScript 研究网页，用原创界面整理 [fxyadela/write-then-publish](https://github.com/fxyadela/write-then-publish) 的产品作用、能力边界、处理原理、使用场景与可扩展方向，并关联上游真实导出证据和可直接操作的双输出 Demo。

> 本项目不是上游产品的复刻版，也不重新托管其 UI 或源码。证据区的两张工作区截图和两项 PNG 是固定提交在本轮真实运行中产生的研究证据；互动实验中的 Markdown 分页和长文排版仍是我们的教学模拟。ZIP、Live Photo、Supabase、Obsidian 写回和公众号草稿箱同步未在本轮执行。

研究事实固定到上游提交 [`7a708312247e69155ca586c49c65c5306fd88e9e`](https://github.com/fxyadela/write-then-publish/tree/7a708312247e69155ca586c49c65c5306fd88e9e)（2026-08-31 验证），避免把后续变化混入本次结论。上游许可证以该提交的 [LICENSE](https://github.com/fxyadela/write-then-publish/blob/7a708312247e69155ca586c49c65c5306fd88e9e/LICENSE) 为准。

## 运行

需要 Node.js `^20.19.0 || >=22.12.0`（Vite 7 的运行要求）与 npm。本轮验证环境为 Node.js 22.15.0、npm 10.9.2。

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

`vite.config.js` 使用 `base: './'`，构建产物可部署到静态子路径；核心页面没有远程字体、图片、脚本或 CDN 依赖。

在线地址：<https://yydshly.github.io/0831_codex_project/demos/write-then-publish-lab/>

## 演示原理

本 Demo 先把有限 Markdown 子集安全解析成块级结构，再让两个纯 DOM 渲染器消费同一份数据。支持的子集是一级至三级标题、段落、引用、无序列表，以及成对的 `**粗体**`；它不是完整 Markdown 实现。

```text
Markdown 字符串
  → 安全块解析（标题 / 正文 / 引用 / 无序列表）
  ├→ 估算预切 → 实际 DOM 测量纠偏 → 极端滚动兜底 → 3:4 卡片预览
  └→ 连续文档流 → 公众号长文预览
```

卡片渲染采用三段式策略：先按块类型和字符数做权重预算与预切，减少首轮溢出；再把候选页真实渲染到 DOM，用 `scrollHeight` 与 `clientHeight` 检查并移动或拆分溢出块；如果极端内容经过有限轮纠偏仍无法装入，则让该页变为可聚焦的页内滚动区。文本切分优先使用 `Intl.Segmenter` 的字素边界，避免拆断 emoji 等组合字符。

卡片页数只用于说明“内容模型与输出布局分离”，不等于上游真实分页结果。所有用户文本都通过 DOM 文本节点写入，不作为 HTML 执行；未闭合的粗体标记按字面文本保留。

## 研究边界

- 上游事实基线：2026-08-31，固定提交 `7a708312247e69155ca586c49c65c5306fd88e9e` 的 README、PRODUCT、LICENSE 与源码结构。
- 上游采用个人非商业许可证；商业使用、公司或客户项目应先核对 LICENSE 并取得必要授权。
- 页面不声称能直接发布到小红书；公众号草稿箱能力限特定本地配置，且不等于直接群发。
- “本地优先”并不等于每条路径完全离线：上游 README 明确区分浏览器本地生成、账号云同步与能力兜底路径。
- 当前同步 DOM 分页已用 50,000 个中文字符验证，可生成 512 页且没有卡片溢出或文本丢失；但数百页 DOM 会显著增加页面体量。它说明 Demo 能承受数万字级研究夹具，不构成无限输入、长文生产性能或虚拟化承诺。

## 无障碍与响应式

- 语义化 `header`、`main`、`section`、`article`、`nav`、`button`、`textarea` 与表格。
- 关键操作支持键盘、可见焦点、`aria-live` 和步进器方向键导航。
- `prefers-reduced-motion: reduce` 下关闭非必要过渡与滚动动画。
- 设计目标覆盖 1440px、768px 和 390px；窄屏按“输入 → 卡片 → 长文 → 分析”顺序堆叠。

## 研究网页结构

- 入口：brief-led greenfield implementation，经 Revision 2 整理为“研究档案 + 互动实验”。
- 视觉：原创技术编辑部风格，纸张/墨色中性色，珊瑚色表示主动操作，青绿色表示已验证数据流。
- 主流程：读取最终理解 → 核对上游真实导出 → 按五问进入研究章节 → 编辑同一份内容并对比教学双输出 → 复核证据账本与最终判断。
- 范围：纯静态前端；无后端、登录、真实平台 API、媒体上传或编码。

- 页面运行时外部资源列表为 `[]`；50,000 中文字符、长粗体、5,000 emoji、未闭合粗体和 XSS 文本夹具均通过。
