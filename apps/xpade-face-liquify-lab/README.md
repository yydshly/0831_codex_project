# XPADE Face Liquify 能力实验室

这是一个独立、离线可用的 Vite + Vanilla JavaScript 概念 Demo。页面先用六组本地写实虚拟人物样片展示人像产品的目标效果，再用原创合成 SVG 说明 [XPADE Face Liquify 研究条目](../../research/xpade-face-liquify/) 中梳理的能力、技术原理、适用边界与扩展路线，并把几何能力放进“企业职业头像”这一具体业务流程中观察。

> 写实图片是通过图像生成工具制作的虚拟人物预生成对照，只用于说明产品目标效果；它们不是当前网页或 XPADE 库实时处理真人照片的实测结果。本项目不运行真实人脸检测，不上传照片，也不向 HR 或服务器提交数据。

## 运行

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 4180
```

开发规范地址为 `http://127.0.0.1:4180/`。生产构建与本地预览：

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 4180
```

`vite.config.js` 使用 `base: './'`，构建产物可放在 GitHub Pages 子路径或任意静态目录中。

在线版本：[GitHub Pages](https://yydshly.github.io/0831_codex_project/demos/xpade-face-liquify-lab/)

## 可以演示什么

- 在企业头像、简历求职、视频形象、电商人像、虚拟试妆和创作者头像六类场景之间切换，查看同一虚拟人物的写实前后对照。
- 拖动原生范围控件，连续比较 0%—100% 的处理前/目标效果；也可一键查看完整处理前或完整结果。
- 同步阅读每个场景的业务对象、输入问题、目标效果、能力组合、产品价值与技术边界。
- 从一张预置的合成随拍出发，完成“照片检查 → 应用企业规范 → 查看职业头像 → 员工确认 → HR 本地审核模拟”的最小业务流程。
- 切换企业头像模板，观察构图、背景、光线与着装如何共同形成统一的职业形象。
- 单独开关 XPADE 几何微调，辨认当前几何能力与职业头像产品层之间的关系。
- 调节眼睛大小、眼距、鼻宽、嘴角、脸宽和下颌，观察原创 SVG 肖像的几何变化。
- 开关语义网格；按住“查看随拍”做前后对比；撤销、重做或重置参数。
- 页面状态自动写入浏览器 `localStorage`，刷新后恢复；存储不可用时仍可正常操作。
- 通过五步步进器理解“输入 → 468 关键点 → 语义控制 → RBF + 面部蒙版 → 三角网格导出”。
- 区分原网页已验证能力、当前 Demo 的概念模拟，以及仍需工程验证的扩展建议。

## 写实多场景效果对照

建议先访问 `#real-cases`。选择任一场景后，拖动人物画面下方的“拖动比较”控件；左侧显示预生成目标效果，右侧显示处理前参考。当前场景和分界位置会单独保存在浏览器 `localStorage`，不会保存图片字节。

| 场景 | 目标产品 | 关键边界 |
| --- | --- | --- |
| 企业头像 | 企业 AI 头像工作台、员工资料系统 | XPADE 只对应可选的局部几何层，仍需质检、背景、皮肤、着装与审批能力 |
| 简历求职 | 招聘平台、职业照服务 | 不用于招聘评分；低质量输入应提示重拍 |
| 视频形象 | 视频美颜 SDK、会议与直播工具 | 静态样片不能证明帧间稳定、防抖、实时延迟或端侧性能 |
| 电商人像 | 批量商品人像处理平台 | 不得改变商品颜色、材质或版型，需要差异检测与人工抽检 |
| 虚拟试妆 | 美妆试色、电商与门店 AR | 视觉预览不等于真实上妆保证，需要色号、材质与相机校准 |
| 创作者头像 | AI 头像工作台、社交内容工具 | 换景与风格化涉及肖像授权、身份偏移与内容合规 |

12 张最终资产位于 `public/assets/photo-cases/`，统一为 `760 × 1014` WebP，总量约 `0.95 MiB`。页面只加载当前选中的一对图片；加载失败时显示可读占位，场景文案和其他演示仍可继续使用。

## 企业职业头像业务演示

演示目标不是把员工“变成另一个人”，而是说明普通随拍如何在保持身份特征的前提下，被整理为真实、专业、符合企业规范的头像。页面使用固定合成肖像，因此不会要求或接收用户照片。

建议按以下路径操作：

1. 在初始状态查看合成随拍和“单人正脸、清晰、无遮挡”等本地示例检查结果。
2. 点击“生成职业头像”，观察页面把构图、背景、光线、着装与轻度几何参数组合为职业头像预设。
3. 在结果状态切换企业模板，确认模板只改变背景和着装强调色，不改变人物身份。
4. 关闭“XPADE 几何微调”，观察脸部轮廓恢复，而背景、构图、光线和着装继续保留。
5. 按住“查看随拍”进行完整前后对比；如需继续检查六组底层语义参数，可回到页面上方的“语义液化实验台”。
6. 依次点击“员工确认”和“HR 批准”，完成本地审核模拟；这些动作不会发送或导出任何数据。

职业头像效果由不同层次共同组成：

| 演示模块 | 可见效果 | 能力归属 |
| --- | --- | --- |
| 照片检查 | 展示单人、清晰度、角度和遮挡等准入反馈 | **产品层概念模拟**；没有执行真实检测 |
| 构图校正 | 合成人物从略偏、略小调整为居中的统一头肩比例 | **产品层概念模拟** |
| 背景、光线与着装 | 随拍环境切换为企业模板背景，均衡面部光线并显示职业着装 | **产品层概念模拟**；不代表真实分割、重打光或服装生成 |
| XPADE 几何微调 | 以克制参数调整脸宽、下颌、嘴角等 SVG 几何 | **当前 Demo 实际驱动的几何层**；仍是合成 SVG，不是真实照片处理 |
| 确认与交付 | 展示员工确认与 HR 本地审核模拟 | **产品层概念模拟**；没有真实 HR 系统、批量导出或后端提交 |

这种拆分刻意保留了能力边界：XPADE 当前提供的是人脸几何调整思路，完整职业头像产品还需要照片准入、分割、背景、光线、皮肤、模板、审核和交付等能力。

## 技术边界

本 Demo 以合成 SVG 实际驱动几何控制，同时用预设状态模拟职业头像业务效果，并用预生成写实图片表达六类产品的目标观感。它没有 MediaPipe 推理、真实 468 点数据、照片质量检测、像素级 RBF 求解、WebGL 纹理重采样、人像/头发/背景分割、皮肤修复、真实换装、视频时序处理、多人脸选择、图片上传或图片导出。写实对照、网格、关键点、照片检查、背景、光线和着装均不应作为生产级算法精度证据。

页面中的“处理中”只表示正在组合本地演示参数，不表示模型推理；“员工确认”和“HR 批准”只改变当前浏览器中的演示状态，不代表提交给企业或 HR。职业头像模板是产品方向说明，不代表上游页面已经具备相应能力。

核心页面不依赖网络、远程字体、图床或 CDN；依赖只用于本地开发与打包。

## 无障碍与响应式

- 使用原生 `button`、`input[type="range"]`、`input[type="checkbox"]`、单选组和有序列表。
- 支持键盘操作、可见焦点、`aria-live` / `aria-busy` 状态反馈和 `prefers-reduced-motion`。
- 写实对比器支持 Home、End 与方向键；场景按钮使用 `aria-pressed`，图片有动态替代文本和固定宽高。
- 桌面为双栏工作台；在 768px 和 390px 下改为单栏，无固定侧栏。
