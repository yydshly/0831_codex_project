# MODNet model attribution

`modnet_photographic_portrait_matting.onnx` is the official photographic portrait matting model converted to ONNX and linked from the official MODNet repository.

- Project: https://github.com/ZHKKKe/MODNet
- Model link: https://drive.google.com/file/d/1cgycTQlYXpTh26gB9FTnthE7AvruV8hd/view
- License: Apache License 2.0
- Local usage: browser-only portrait alpha matte inference; camera frames are not uploaded.

The model file is unmodified. Application preprocessing, scheduling and compositing are implemented by RealHuman.
