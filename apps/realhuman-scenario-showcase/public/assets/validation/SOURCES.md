# Validation image sources

The four `portrait-*.webp` files are synthetic demonstration fixtures copied from the sibling XPADE capability lab in the same workspace. They are used only to test technical stability across varied apparent skin tones, gender presentation, framing, and slight pose changes. They are not evidence of results on real customers and must remain labelled as synthetic in the UI.

Real-photo candidates were identified on Wikimedia Commons, but the current environment could not complete TLS downloads from the media server. No external real portrait has therefore been added in this revision.
